# 🧠 Brain Tumor Detection & Classification System

An interactive web application built with **Streamlit** and **TensorFlow / Keras** that classifies brain MRI scans into four distinct categories with high accuracy.

---

## 🌟 Key Features

* **Instant Classification:** Detects whether an MRI scan contains a tumor and identifies its specific type.
* **4-Class Prediction:** 
  * 🔴 Glioma Tumor
  * 🟡 Meningioma Tumor
  * 🟢 Pituitary Tumor
  * 🔵 No Tumor
* **Confidence Score:** Provides the model's confidence level for every outcome.
* **Medical Context & Description:** Automatically displays educational descriptions for each detected tumor type.

---

## 🛠️ Tech Stack & Libraries

* **Language:** Python
* **Deep Learning Framework:** TensorFlow / Keras (CNN Model)
* **Web Interface:** Streamlit
* **Image Processing:** Pillow / OpenCV
* **Data Manipulation:** NumPy
